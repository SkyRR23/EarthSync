# Research quarantine — not live crop knowledge

`myanmar-reference-only.json` preserves the 12 contributed profile assertions
with original archive/member identity. Every profile remains recommendation-
ineligible, candidate-ineligible and without executable rules. The schema is
deliberately separate from the live crop catalog. No application imports this file.

Eleven ECOCROP datasheets were readable for bounded numeric desk review. Sunflower
returned a direct service error; the indexed original source matches its numeric
reference, retained as cached-only with explicit uncertainty. Annual rainfall is
not seasonal crop demand. Temperature envelopes are not verified daily air limits.
Team durations, calendars, water, N, pest, root-depth and residue claims require
parameter-specific source/applicability acceptance.

Exact-calendar rainfall normals are offline modeled reference arithmetic from
contributed raw responses. Each year-month must be present and valid; values are
multiplied by their actual calendar days before averaging. Headers, units and
geometry remain attached. They are neither farm measurements nor crop rules.

Regenerate only after the original ZIP passes its pinned checksum:


fields, team confidence or file naming. See `docs/science-audit/` for the audit,
provenance gaps, current repairs and independent scientific acceptance limits.
