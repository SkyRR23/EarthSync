# Source rights and provenance

Software in this increment follows the repository's applicable license. Source
data retain their own terms; this directory is not a blanket relicensing of FAO,
ISRIC, USDA, institutional publications or third-party material.

| Material | Reuse basis and package treatment |
| --- | --- |
| ECOCROP | Official FAO CKAN record `f41561fe-bead-4012-ac7a-dc4f34473c2d` explicitly identifies CC BY 4.0. Exact metadata, five original sheets and field-help responses are retained with FAO attribution. |
| OpenCLIM ECOCROP CSV | FAO-derived data snapshot pinned to `ea43ecd418fd1a1ea08d32c7dce64b7fae02dec4`, original Windows-1252 bytes preserved. Underlying FAO data license is established independently. This is a third-party mirror, not an official export. No license for OpenCLIM code is assumed; no code copied. |
| GAEZ v5 master configuration | Official package `dc08a00f-db26-42bf-b59b-871a3bb69e36` declares CC BY 4.0. Exact configuration and a lightweight parsed reference are retained. No numerical global raster or potential-yield product is redistributed. Product-specific/third-party terms require a separate check. |
| SoilGrids | ISRIC documents CC BY 4.0 for maps. Two small exact WCS diagnostic captures are retained, with source/query/hash and rejection status. They are not accepted soil observations. |
| FAO Crop Calendar | No dataset-specific license for this API was established. Only selected factual dates, numerical durations, zone identifiers and short context are retained. Full responses, country-download XLSX, images/media and app code are not redistributed. Broad global calendar redistribution remains blocked pending rights review. |
| FAO Myanmar handbook (2022) | ISBN 978-92-5-136276-1; DOI `10.4060/cc0246en`; CC BY-NC-SA 3.0 IGO, with separate third-party rights. | NASA | Existing validated POWER captures/contracts are reused without copying a new pipeline. New CMR access is metadata discovery only. Granule-specific quality, authorization and terms remain prerequisites for numerical use. |

Required attribution for the retained ECOCROP data: **Food and Agriculture
Organization of the United Nations (FAO), ECOCROP ecological crop database**;
official access: https://ecocrop.apps.fao.org/ecocrop/srv/en/home ; license:
https://creativecommons.org/licenses/by/4.0/ . The CSV was retrieved through the
identified OpenCLIM mirror. EarthSync adds agricultural-category filtering,
identity aliases, structured claims and missingness; these changes do not imply
FAO endorsement or independent crop validation.

GAEZ attribution: **FAO and IIASA, Global Agro-Ecological Zones v5**, official
master configuration and model documentation. Soil attribution: **ISRIC — World
Soil Information, SoilGrids**; retain the recorded native product identity and
diagnostic limitations. The FAO handbook citation is **FAO. 2022. Handbook on the
integrated crop management of groundnut and sesame for farmer field schools in
central dry zone of Myanmar. Nay Pyi Taw. https://doi.org/10.4060/cc0246en**.

Original-response SHA-256 and byte lengths apply only to the indicated captured
bytes. `original_file: null` means those full response bytes are not redistributed
in this package; a stored hash/extract is not a stored original. All content is
reference-only. Unresolved licenses, publication dates, exact release identities
and independent applicability remain explicit limitations, not inferred grants.
