# Soil appearance is not chemistry

Soil labels describe surface cracking, possible crusting, standing water, possible
erosion, visible organic debris, exposed roots, dark/light appearance and possible
compaction-related surface signs. Surface signs cannot establish measured
compaction or laboratory texture. Camera lighting and processing change soil color.

No photo can measure pH, N/P/K, salinity, organic carbon percentage, CEC, exact
moisture percentage or validated crop suitability. Dark/light color has no chemical
explanation mapping. A saved SoilGrids pH is displayed under regional modeled
evidence with original depth and cells, never under image measurements.

Laboratory reports use their own endpoint and schema. Local Tesseract always runs
first. Optional, explicitly requested and consented AI assistance transcribes
printed rows; the same conservative parser rejects absent units and ambiguous
samples/depths. Missing fields are left missing. Local and AI original transcription,
parameter, value, unit, lab, sample/date, depth, method and row locator are retained
inside the existing report document; outer photo ID locates the private original.
Both originals remain separate from user-confirmed corrections. The original image
is available in the correction editor. The user must inspect it, correct values
and explicitly confirm a single sample. Confirmation never authenticates the report
or establishes whole-field chemistry. AI can misread or invent a transcription:
manual review is mandatory, and no AI value silently becomes confirmed evidence.
