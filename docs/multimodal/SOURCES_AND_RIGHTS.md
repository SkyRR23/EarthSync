`server/earthsync/research/plant_health.json` contains original short factual
paraphrases with exact source URLs, locators, publisher, date when established,
original geography and limitations. No article, photograph, logo, table or training
image is copied. A public source link does not grant an image/dataset license.

The official Iowa State pages "Plant color differences based on management and
weather" (June 11, 2007) and "What causes striped corn leaves?" (Angie Rieck-Hinz
and Antonio Mallarino, June 11, 2021) were checked using web retrieval on
2026-11-15. They support several potential yellowing/striping explanations and
additional field/laboratory investigation, not photographic diagnosis. The official
University of Minnesota Extension "Soil compaction" page was checked the same day;
its publication date was not established. It supports cautious interpretation of
surface physical clues. Exact URLs and section locators are in the dossier.

No broad reuse license is assumed. Only attributed original factual paraphrases
and links are redistributed; full-text/image reuse requires checking owner terms.
Direct shell retrieval was blocked by this environment's domain allowlist, so
verification used web retrieval. No raw-page archival hash is claimed. The dossier
hash identifies EarthSync's own paraphrase collection. Independently review the
paraphrases and local relevance before agricultural rollout.
